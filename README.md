# ダムダムボーイ風メダルゲーム

KONAMIのメダルゲーム「ダムダムボーイ」にインスパイアされた、ブラウザで遊べるバスケットボールのメダルゲームです。

## 遊び方

1. メダル10枚でスタート。1プレイにメダル1枚が必要です。
2. プレイを開始すると、キャラクターがドリブルしながら横にスクロールします。
3. ランダムな点数が書かれたバスケットゴールが並んでいます。
4. 「シュート！」ボタン（またはスペースキー / 画面タップ）を押すと、最も近いゴールに向かってシュートします。
5. **点数が低いゴールほど入りやすい！** シュートが入ると、点数と同じ枚数のメダルがもらえます。
6. メダルがある限り「もう一度遊ぶ」で続けられます。0枚になったら「今日はおしまい」。

## 技術構成

- HTML / CSS / Vanilla JavaScript（Canvas API）のみ。ビルド不要の静的サイトです。
- 効果音はWebAudio APIで生成しており、外部アセットはありません。
- `main` ブランチへのpushで、GitHub Actions経由でGitHub Pagesに自動デプロイされます。

## ローカルで遊ぶ

```sh
# 任意の静的サーバーで配信（例）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## GitHub Pagesの有効化

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
